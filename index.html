What each one does

Structure and meaning

HTML is a set of tags that label every piece of content: headings, paragraphs, links, images and forms.

  • Tags like <h1> and <nav> tell browsers and screen readers what things are.
  • Links connect pages to each other.
  • Every website starts here.
<article>
  <h1>Hello, web</h1>
  <a href="/about">About me</a>
  <img src="cat.jpg" alt="A cat">
</article>

Style and layout

CSS selects elements and sets how they look: colors, fonts, spacing and where things sit on screen.

  • Flexbox and Grid arrange content in rows and columns.
  • Media queries adapt a layout to phones and desktops.
  • Transitions animate changes smoothly.
.button {
  background: royalblue;
  padding: 0.6rem 1.2rem;
  border-radius: 99px;
  transition: transform .2s;
}
.button:hover { transform: scale(1.05); }

Behavior and logic

JavaScript runs in the browser and reacts to what people do: clicks, typing, scrolling and more.

  • It reads and changes the page while it’s open.
  • It fetches fresh data without reloading.
  • It powers games, forms, dashboards and apps.
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  document.body.classList.toggle("dark");
});
